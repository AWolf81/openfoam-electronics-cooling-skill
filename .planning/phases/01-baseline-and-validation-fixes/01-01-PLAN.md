<task type="auto">
  <name>Task 1: Write .github/regression.sh</name>
  <files>.github/regression.sh, .github/workflows/codeql.yml</files>
  <action>
Bash script, `set -euo pipefail`, usage `.github/regression.sh [REF]` (default `v0.1.0`).
- Create a temporary directory with `mktemp -d` and remove it on exit (`trap`). Inside it, `git worktree add --detach <tmp>/base REF` (and `git worktree remove --force` in the trap). Never write into the repo itself.
- Case list: every `*.yaml` under `assets/` and `evals/` in the WORKING tree. For each, if the same path does not exist in the baseline, run only the working tree and report "new case, no baseline" (not a failure).
- For each case, in both trees: `python3 <tree>/scripts/hand_calc.py <yaml>` → stdout to `<tmp>/<side>/<case>/hand.txt`; `python3 <tree>/scripts/make_case.py <yaml> <tmp>/<side>/<case>/case --resolution coarse` (the CASE path must be the same relative layout on both sides so generated text matches).
- Compare: `diff -u` of hand.txt; `diff -r` of the two case directories. Before comparing, check whether generated files embed absolute paths or timestamps (inspect `case-meta.json`, `Allrun`, `system/controlDict`): if so, normalise them with `sed` on copies (replace the tree prefix with `<TREE>`), and say so in a comment. Do not hide real differences.
- Print one line per case: `same`, `DIFF (hand calc)`, `DIFF (case: <files>)` or `new`; exit 1 if any DIFF.
- Use the YAML path relative to the repo for both sides (baseline YAML from the baseline worktree, so a changed YAML shows up as a difference).
- Add `.github/regression.sh` to the ShellCheck step in `.github/workflows/codeql.yml` only if the glob `.github/*.sh` does not already cover it (it does: check, then leave the workflow unchanged if so).
  </action>
